Политика конфиденциальности приложения DayMyQuest
Дата последнего обновления: 09.10.2026

1. Общие положения
Настоящая Политика конфиденциальности (далее — «Политика») описывает, как приложение DayMyQuest (далее — «Приложение») собирает, использует и защищает информацию пользователей.

Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

Оператор персональных данных:
Разработчик приложения DayMyQuest (физическое лицо)

2. Какие данные собирает Приложение
2.1. Данные, которые хранятся только на вашем устройстве
Приложение не передаёт следующие данные на сторонние серверы:

Задачи, их названия, описания, даты, повторы

Категории и их названия

Поощрения и покупки

Количество монет (листочков)

Прогресс по карме, челленджам и разнообразию

Настройки приложения (тема, звук, уведомления)

Все эти данные хранятся локально на вашем устройстве в защищённой области приложения и не передаются третьим лицам.

2.2. Данные, связанные с рекламой
Приложение использует рекламные SDK (Yandex Mobile Ads, VK Ads). Эти SDK могут автоматически собирать:

Рекламный идентификатор устройства (Advertising ID)

Данные об устройстве (модель, версия Android, язык, регион)

Данные о взаимодействии с рекламой (показы, клики)

Эти данные используются исключительно для показа персонализированной рекламы и не позволяют идентифицировать вас как личность. Сбор происходит автоматически, даже если вы не авторизованы в Приложении.

3. Разрешения, которые запрашивает Приложение
Приложение запрашивает следующие разрешения:

Разрешение	Зачем
Уведомления	Для показа напоминаний о задачах
Точные напоминания	Для точного времени уведомлений
Камера	Для создания фото-вложений к задачам
Файлы и медиа	Для выбора фото/файлов из галереи
Интернет	Для загрузки рекламы
Вибрация	Для тактильного отклика при выполнении задач
Все разрешения используются только для заявленных функций и не передаются третьим лицам.

4. Передача данных третьим лицам
Приложение не продаёт и не передаёт ваши личные данные третьим лицам, за исключением:

Рекламных сетей (Yandex Mobile Ads, VK Ads) — передаётся рекламный идентификатор и технические данные устройства для показа рекламы

5. Хранение и защита данных
Все данные хранятся локально на вашем устройстве. Приложение не использует облачные серверы для хранения ваших задач и настроек.

Вы можете удалить все данные в любой момент через раздел «Настройки → Очистить все данные».

6. Управление рекламой
Вы можете отключить персонализированную рекламу в настройках вашего устройства:

Android: Настройки → Google → Реклама → Отключить персонализацию рекламы

7. Дети
Приложение не предназначено для детей младше 13 лет. Мы не собираем данные детей сознательно.
